# Portfolio — Máximo Bonarrico

Portfolio personal de ciberseguridad. HTML, CSS y JavaScript vanilla, sin frameworks.

🌐 **Live:** https://maxi414.github.io

## Stack
- HTML + CSS + Vanilla JavaScript
- Diseño dark mode con estética terminal
- Sin dependencias ni build

## Estructura
```
.
├── index.html          
├── css/
│   └── style.css       
├── js/
│   └── main.js        
└── assets/
    ├── foto.jpg
    ├── favicon.ico
    ├── og-image.png
    └── CV_Bonarrico_Maximo.pdf
```

## Editar contenido
Skills, labs y certificaciones se editan en los arrays al inicio de `js/main.js`.
Para marcar un lab como terminado: cambiar `status` a `'done'` y poner la `url` del repo.
